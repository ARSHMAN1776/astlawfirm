## Overview

**AST Law Firm (Ahmed Sabir Tanoli)** is an elite legal practice in Pakistan representing clients before the **Supreme Court of Pakistan**, **High Courts**, and specialized regulatory tribunals. Rooted in the 1992 foundation of **Tanawal Law Associates (TLA)** by **Haji Sabir Hussain Tanoli** (Advocate Supreme Court of Pakistan) and unified under the managing partnership of **Ahmed Hussain Tanoli** (Advocate High Court), the firm combines thirty-four years of courtroom trial advocacy with modern corporate advisory.

## Getting Started

### Prerequisites
- Node.js 18.17+ or later
- npm, yarn, or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ARSHMAN1776/astlawfirm.git
   cd astlawfirm
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.

### Building for Production

```bash
npm run build
npm start
```
